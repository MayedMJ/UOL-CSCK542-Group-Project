# UOL-CSCK542-Group-Project

University record management system for the CSCK542 Database Connection
Assignment, using Python and SQLite.

## Running tests

Requires Python 3 with SQLite 3.37 or later. No external packages are needed.

Run from the project directory:

```bash
python3 -B -m unittest -v test_queries
```

Tests create their own in-memory database.
